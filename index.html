01 / Expertise

01 / 05

Advice and delivery, connected.

Technical consulting and full-stack development are one line of work: the architecture we recommend is the architecture we build. Our deepest experience is in financial systems and agentic workflows.

Advice and build

Specialisms

Technical consulting

Clarify the problem before choosing the technology. We define requirements, assess technical choices and set out a practical architecture and delivery plan.

  • Requirements and scope
  • Architecture and data model
  • Assessment of technical options
  • Delivery plan

Full-stack development

Build the whole system and put it into production. We develop interfaces, backend services and integrations, and set up the cloud infrastructure as code, with testing and deployment from the first release.

  • Web and mobile interfaces
  • Backend services and APIs
  • Integrations
  • Cloud infrastructure as code

Financial systems

Systems where amounts have to add up and decisions have to be traceable. We build financial platforms, backend systems and the information flows that support financial operations.

  • Leasing and lending platforms
  • Private equity platforms
  • Broker and dealer portals
  • Financial data models

Agentic workflows

AI agents with a specific job in a business process. They recognise documents, extract information, coordinate workflow steps and carry out standard operating procedures, with people reviewing the results.

  • Document recognition and OCR
  • Information extraction
  • Workflow coordination
  • Standard operating procedures

02 / Approach

02 / 05

From problem to production.

One continuous line from advice to implementation. We make the architectural decisions and build the system ourselves, set up its infrastructure and hand it over, so every decision is tested in working software and carried through to production.

  1. 01 / Problem

    Understand the problem.

    We start with the business: the process, the people involved, the information they need and the decisions the system has to support.

    Result
    Requirements and a clear scope for the first release.
    Led by
    Technical consulting

  2. 02 / Architecture

    Design the system.

    We assess the technical choices and set out the architecture: data model, interfaces, integrations, cloud infrastructure and the steps where AI agents take part.

    Result
    An architecture and a delivery plan in small, usable increments.
    Led by
    Technical consulting and full-stack development

  3. 03 / Development

    Build it.

    We build the interfaces, backend services and integrations with agentic software engineering: AI agents write and test code under our direction and review, with automated tests and deployment from the first increment.

    Result
    Working software, reviewed with you in short cycles.
    Led by
    Full-stack development

  4. 04 / Infrastructure

    Set up the infrastructure.

    We set up the cloud infrastructure on a provider such as AWS or Azure, defined as code with tools such as Terraform, so every environment can be rebuilt, reviewed and changed like the software itself.

    Result
    Production and test environments in code, with automated deployment and monitoring.
    Led by
    Full-stack development

  5. 05 / Production

    Run it and hand it over.

    We release the system, monitor it and improve it with the people who use it. Then we hand it over: the code, the infrastructure definitions, the documentation and the knowledge your team needs to run it.

    Result
    A system in production that your team owns.
    Led by
    Full-stack development and technical consulting

  • Precise

    Make decisions, responsibilities and outcomes clear.

  • Inventive

    Explore better ways to solve the business problem.

  • Practical

    Carry the work through to production.

03 / Work

03 / 05

Built from the ground up.

Since 2004, re-invention has designed and built complete systems, from interface to infrastructure: mostly financial information systems for fintech companies, and also systems for enterprises such as IKEA, ING and Tele2.

  1. 2026 / CTO

    Financial systems / Full-stack development

    Problem
    Individual private equity investors tracked capital calls on each fund’s own schedule and valuations in quarterly PDFs, without the systems institutions use, and had few ways to sell a position or raise cash against it.
    Contribution
    As CTO, built the Peliqan platform from the ground up: portfolio management, a marketplace for private equity secondaries and NAV loan lending facilities, with values extracted from investment reports and traceable to their source.
    Outcome
    Investors see their whole portfolio and can act on it: sell a position, finance a commitment, plan ahead.

  2. 2025–2026 / Lead developer

    Full-stack development

    Problem
    Progressive lenses are hard to compare in a store: customers only notice the difference between lens designs once they wear them.
    Contribution
    Built a lens experience simulator for the browser: a photorealistic street, captured as a Gaussian splat, seen through virtual glasses that render each lens design, with head tracking on the phone’s gyroscope.
    Outcome
    Customers ride a bike through the street, swap the lens design for each eye and see the difference for themselves.

  3. 2024–present / Tech lead

    Financial systems / Full-stack development

    Problem
    A fintech start-up in asset leasing needed an asset-backed lending platform for brokers.
    Contribution
    Set up the backend platform that runs the lease process for brokers and their customers.
    Outcome
    Customers get their lease in the time it takes to drink two cups of coffee.

  4. 2023–2024 / Tech lead

    Full-stack development / Financial systems

    Problem
    Car dealers needed a faster way to handle their customers’ lease requests.
    Contribution
    Led the development of a dealer portal that takes a lease from the customer’s request to a finalised contract.
    Outcome
    Dealers finalise a lease and deliver the vehicle in the time it takes to drink two cups of coffee.

  5. 2022–2023 / Tech lead

    Technical consulting / Full-stack development

    Problem
    Sales co-workers struggled to find the information they needed for their work.
    Contribution
    Led the development and technical implementation of the Content Coworker Experience programme, built on a knowledge graph.
    Outcome
    Co-workers get information personalised to them, through a new interface on top of the knowledge graph.

  6. 2019–2022 / CTO

    Technical consulting / Full-stack development

    Problem
    Homigo, a corporate start-up backed by ING Neo, needed a platform where contractors and homeowners manage home renovations.
    Contribution
    As CTO, led the technical implementation and designed and built the most demanding features.
    Outcome
    A SaaS platform on mobile and web, with real-time chat, file sharing and resource planning for renovation projects.

  7. 2016–2019 / Tech lead

    Financial systems

    Problem
    A fintech start-up in leasing needed an online leasing platform and the information system behind it.
    Contribution
    Developed the leasing platform from the ground up. Designed and implemented BEEHIVE, the information system that captured and automated core business processes, with a GraphQL API for the dealer portal and the customer portal.
    Outcome
    In 2022 BEEQUIP provided €735 million in lease financing. In 2024 the company was acquired by Apollo.
